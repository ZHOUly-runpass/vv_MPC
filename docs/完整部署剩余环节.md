# 开发机完整部署剩余环节

## 已完成

- 核心规划、安全监督、ROS 2 包、开发机测试和 GitHub 部署。
- UniLION 官方代码固定为 submodule。
- 官方 LCT checkpoint 已下载并完成双端 SHA-256 校验。
- 已抽取 911 项 LiDAR 初始化子集，并在本地与开发机完成哈希一致性校验。
- 开发机项目隔离环境已完成 CUDA 扩展编译；PyTorch、MMCV、MMDetection3D、Mamba 和 `projects.mmdet3d_plugin` 冒烟测试全部通过。
- 已实现并严格加载单帧 `FrozenLidarBackbone`，完成12000点合成C16格式 CUDA 前向、四级BEV hook、有限值、特征方差、显存、时延和重复性检查。
- CasADi 热态 1/8 障碍满足 80 ms；32 个近场障碍超时会停车。

## 仍缺少

### UniLION

- 合法取得 nuScenes mini/sample 原始点云后补跑官方真实样例；当前开发机没有该数据。
- 用 C16/仿真 16 线点云完成 100 帧数值、分辨率和延迟验证。
- 许可证尚不明确，不能视为可自由再发布或商业部署。

### 仿真

- 开发机未安装 Nav2。
- 尚无差速仿真 URDF、16 线 LiDAR、8 个 world、GT bridge 和 benchmark manager。
- 尚未完成 DWB/MPPI/Vanilla D-CBF/Proposed 四组公平基线。
- 尚未采集 ROS simulation dataset、feature cache 和 teacher labels。

### 实车

- R680/C16 驱动和硬件当前不在线。
- 车型、轮廓、外参、物理限制、方向、延迟、制动和急停仍未实测。
- `/odom`、IMU、点云、路径和 costmap 真实话题/QoS 未确认。
- 23 个实车 validation gates 不得提前解锁。

### 性能与训练

- 32 个同时可达近场障碍仍超过 80 ms，需要稀疏求解/acados 或安全降级策略。
- 候选头和安全头只有 GPU smoke test，尚无正式训练数据和指标。
- 尚无端到端 C16→BEV→候选→MPC 延迟报告。

## 当前完成度边界

“已部署 UniLION”目前指代码、权重、隔离依赖、CUDA 编译与插件导入已就绪；不代表模型已对 C16 输入完成推理，更不代表冻结门可以解除。项目完整闭环的关键路径仍是：仿真接口 → 16 线点云适配 → backbone 前向 → 特征桥接 → 数据采集/训练 → C16 实测标定与验收。
